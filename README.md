🎬 MoodFlix AIAn AI-driven full-stack application that recommends movies based on real-time facial emotion recognition.🧠 About The ProjectMoodFlix is a decoupled, microservice-style application that leverages advanced Computer Vision to curate personalized film suggestions. By analyzing a live webcam feed, the AI instantly maps human facial expressions to tailored movie genres.✨ Key FeaturesReal-Time Inference: Uses DeepFace and OpenCV to extract and classify facial emotions instantaneously.Decoupled Architecture: A high-performance RESTful FastAPI backend communicates securely with the frontend via base64 image payload processing.Cinematic Dashboard: A sleek, responsive Streamlit UI featuring custom CSS injection for a state-responsive, premium user experience.🚀 Quick Start GuideSince MoodFlix uses a decoupled architecture, you will need to run the backend API and the frontend UI simultaneously.1. Prerequisites & InstallationClone the repository and install the required dependencies:git clone https://github.com/YOUR_USERNAME/moodflix.git
cd moodflix
pip install -r requirements.txt
(Note: DeepFace will download its pre-trained facial recognition weights during the first run).2. Start the AI Backend (Terminal 1)Boot up the FastAPI engine to handle the heavy ML processing.python backend.py
The API will start running on http://localhost:8000.3. Start the Frontend Dashboard (Terminal 2)Open a new terminal window, navigate to the project folder, and launch the Streamlit interface.streamlit run frontend.py
Your browser will automatically open the cinematic dashboard at http://localhost:8501.🛠️ Tech ArsenalDomainTechnologies UsedBackend APIFastAPI, Uvicorn, PydanticComputer Vision / MLDeepFace, OpenCV, NumPyFrontend UIStreamlit, Custom HTML/CSS
